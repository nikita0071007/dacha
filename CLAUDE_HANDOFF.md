# Передача проекта «Бабушкина дача» Claude

## Что это
Android-игра «три в ряд» с дачным сюжетом. Это **исходники действующего прототипа**, а не завершённая версия игры с согласованным новым оформлением.

- GitHub: https://github.com/nikita0071007/dacha
- Рабочая ветка: `feature/marina-wardrobe-v1`
- Pull request: https://github.com/nikita0071007/dacha/pull/1

## Что уже есть в коде
- `index.html`: основной HTML/CSS/JS приложения, игровая логика, сцена дачи, уровни, ремонт дома и забора, персонажи, сохранения в localStorage.
- `app/`: нативная Android-оболочка WebView.
- `scripts/bundle_android.py`: генерирует автономный `app/src/main/assets/index.html`, удаляя удалённые скрипты и шрифты из web-версии.
- `scripts/check_game.py`: статические проверки HTML и JS.
- `tests/browser-smoke.cjs`: тест Playwright (запуск, знакомство, гардероб, сад, уровни, сохранения и генерация поля).
- `.github/workflows/android-debug.yml`: сборка debug APK в GitHub Actions.
- `.github/workflows/browser-smoke.yml`: браузерные тесты и скриншоты.

## Важное предупреждение
Заказчик считает, что выданный APK визуально повторяет **старую игру**, а не обещанную новую качественную мультяшную игру. Скриншот с телефона выявил плохую читаемость бабушки Марины. Впоследствии был добавлен фон сцены и исправлен масштаб SVG персонажа, но новая графика по-прежнему не внедрена полностью. **Не называйте этот прототип готовой новой бета-версией.**

Факты проверки: GitHub Actions для `b92b4c78415036e926515ce579de08f017de97da` собрал APK успешно; браузерные smoke-тесты в ветке проходили. Это **не эквивалент** полного прохождения игры на физическом телефоне.

Последняя тестовая версия Android имеет отдельный идентификатор приложения `ru.gusevmade.dacha.betatest`, чтобы не путать со старой установленной игрой.

## Как собрать
1. `python3 scripts/check_game.py`
2. `python3 scripts/bundle_android.py`
3. `python3 scripts/check_game.py app/src/main/assets/index.html`
4. Android SDK 35, JDK 17 и Gradle 8.9: `gradle :app:assembleDebug`
5. APK: `app/build/outputs/apk/debug/app-debug.apk`

Браузерные тесты: установите Playwright и Chromium, затем `node tests/browser-smoke.cjs`. В CI это настроено в `.github/workflows/browser-smoke.yml`.

## Цели при продолжении
1. Проверить APK на физическом Android/эмуляторе, а не только факт его сборки.
2. Привести графику к согласованному новому стилю; заменить временные рисунки и эмодзи полноценными единообразными игровыми спрайтами.
3. Исправить расположение элементов и масштаб на реальном экране телефона.
4. Проверить обучение, прохождение уровней, ремонт, животных и сохранение после перезапуска.
5. Давать владельцу только проверенные артефакты. Не оценивать готовность необоснованными процентами.

В папке `ok/` и `tg/` есть отдельные web-варианты игры; **основная** Android-сборка использует корневой `index.html`.

Это сообщение — инструкция по передаче разработки, а не подтверждение завершённости функций.
