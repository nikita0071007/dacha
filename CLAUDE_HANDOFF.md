## 2. Новая графика — важнейший пробел
Сохранившиеся исходные изображения — композиционные иллюстрации/концепты, а не игровые asset-файлы. Нет проверенного комплекта: раздельных прозрачных поз Марины, кота и собаки, шести раздельных нарядов, ассетов овощей PNG 256×256, спецфишек PNG, фонов 9:19 без персонажей, элементов UI и пиктограмм.

Имеющиеся оригинальные PNG 1254×1254 без UI содержат целиком Марину, кота/собаку/сад; они **без прозрачности**, ни один не соответствует портретному фону 9:19. Стиль животных на концептах иногда **не соответствует** согласованному виду: Мурка должна быть бенгальской, Шарик — тёмным тигровым французским бульдогом. Марина должна иметь один дизайн: красный платок в белый горошек, синее платье в цветочек, белый фартук, очки.

Сами изображения передаются отдельно как `reference-originals-no-ui`, **не ставьте их в игру как готовые спрайты**. Нужна перерисовка и экспорт отдельными прозрачными PNG/WebP в едином стиле. UI собирать кодом, а не оставлять нарисованные кнопки внутри фона.

## 3. Движок и размер
**Сейчас** HTML/CSS/JavaScript + WebView, Phaser/Unity/Spine/Lottie в репозитории не установлены.
**План** `LIVE_GARDEN_PLAN.md` — постепенно внедрить Phaser 3 для живой сцены, с локальной копией движка в APK. Конкретная версия Phaser не определена; решение можно принять после оценки внедрения.
Реальный последний измеренный тестовый debug APK весит **81 304 байта (около 0,078 MiB)**, но **без новых внешних графических ресурсов**. Размера новой 2.0 не существует, так как набор ассетов не готов. Pipeline сжатия графики не настроен; целесообразность WebP/PNG надо измерить на готовых оригиналах.
Анимации требуются (idle, walk, wave, talk, celebrate, sad; pets idle/walk/react). Формат атласов/спрайт-листов, Spine, Lottie не выбран.

## 5. Сборка
```bash
python3 scripts/check_game.py
python3 scripts/bundle_android.py
python3 scripts/check_game.py app/src/main/assets/index.html
gradle --no-daemon :app:assembleDebug
```
Нужны JDK 17, Android SDK 35, Gradle 8.9. APK: `app/build/outputs/apk/debug/app-debug.apk`. Браузерный тест: Playwright/Chromium, `node tests/browser-smoke.cjs`.

## 6. Рекомендация при принятии проекта
Не оценивать готовность процентами. Сначала отрисовать единообразные отдельные спрайты и фоны, решить архитектуру Phaser, собрать **новый** тестовый APK, затем пройти на устройстве первый запуск → уровень → ремонт → перезапуск/сохранение. Не выдавать концепт-арт за скриншот игры и не использовать поддельные UI-кнопки внутри фона.

## 7. Права
Графика в пакете названа референсами, а не лицензированной библиотекой для релиза. По действующим Terms OpenAI пользователь владеет Output в отношениях с OpenAI, насколько позволяет закон (https://openai.com/policies/terms-of-use/), но не гарантируется уникальность и соблюдение прав третьих лиц. Файлы PNG сами по себе не содержат достоверной истории генерации: точное название модели, параметры, правовой статус каждого изображения не подтверждены. Перед RuStore нужна проверка происхождения и чужих элементов.
