Проверка «Бабушкиной дачи»
Запуск (нужны Node, Playwright и gh):
  bash proverit-vetku.sh feature/marina-wardrobe-v1        # проверить ветку из GitHub
  node verify.js путь/к/index.html 50 папка-отчёта         # проверить локальный файл
Проверяет: размер, синтаксис JS, внешние ресурсы, выдуманную валюту, платёжный код,
запуск и вёрстку на трёх размерах экрана (скриншоты), старые сохранения, прохождение уровней ботом.
Итог: ПРИНЯТЬ / ПРИНЯТЬ С ПРАВКАМИ / ВЕРНУТЬ. Телефон и ощущения от игры скрипт не проверяет.
