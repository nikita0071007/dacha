# CHANGELOG — тестовая ветка Beta 2.0

## 2026-11-10 — Шаг 1a: пропорции (выполнение тестов ожидается)
- Рабочая копия из `claude/art-integration` создана в `beta/index.html`, основной `index.html`, `tg/`, `ok/` не изменены.
- Поле дачи стало выше (отношение 4:5), дом увеличен, Марина и питомцы уменьшены; оба питомца в режиме теста включены.
- Добавлены тест размеров 360×640, 390×800 и 412×915, сохранение скриншотов и проверка реальных DOM-размеров.
- Добавлена отдельная CI-проверка: `node tools/verify.js beta/index.html 50 beta/verify-out`.
- Статус: проверка CI **ещё не завершена**. Не выдавать CSS-формулы за результат проверки на телефоне.

## 2026-11-10 — Шаг 1b: нарастающая сложность (проверка ожидается)
- В `beta/step1.js` добавлены замки с 3 ударами, неподвижные гнилые фишки, вредители, новые смешанные препятствия на уровнях 30–50.
- С 15-го уровня сокращён лимит ходов; сложность и проходимость требуют бот-измерений, коэффициенты не объявляются сбалансированными.
- Новые механики действуют только в `beta/`, живые версии не менялись.
- `node tools/verify.js beta/index.html 50 beta/verify-out` выполняется GitHub Actions при публикации.

## 2026-11-10 — Шаг 1c: анимация фишек (ожидает браузерного тестирования)
- Лёгкое покачивание, сжатие при совпадении, отскок при падении, радость у спецфишек; CSS only.
- Режим `prefers-reduced-motion` отключает эффекты; новые библиотеки не подключены.
- Автотест запускается заново на этой версии; физический Android пока не проверен.

## 2026-11-10 — Шаг 1d: чередование урожая и измерения бота (проверка ожидается)
- Уровни 1–10, 21–30, 41–50: шесть овощей; 11–20, 31–40: шесть фруктов, без смешения.
- Добавлены SVG сладкого перца, свёклы, груши, вишни, сливы, винограда (изображения 64×64, единый объёмный стиль); сохранены подходящие исходные SVG.
- При смене десятка отображается диалог нового урожая с настоящей кнопкой.
- Автотест запускает три игры на каждый уровень и сохраняет таблицу `bot-levels.csv` с измеренным процентом побед; это не математическое доказательство проходимости каждого уровня.
- Отдельная сборка Android берёт `beta/index.html` и `beta/step1.js`, не живой `index.html`.
